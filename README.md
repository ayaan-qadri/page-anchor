Page Anchor lets you draw, highlight and write notes on any website. Your notes are saved to that page, so they're still there when you come back.

Use it to point out problems on a website, give feedback on a design, study an article, or explain a page to someone.

## What you can do

- Draw with a pen or highlighter in any colour and size; highlights keep the text under them readable on light and dark pages
- Add boxes, circles, lines and arrows
- Type notes, and move or edit them later
- Erase, undo and redo
- Select anything you've drawn and move it
- Save the whole page with your notes as an image or a PDF, or print it
- Back up all your notes to a file and restore them any time

Your notes stay next to the right content, even when the page layout changes.

## How to use it

1. Open any page and click the Page Anchor icon, or press `Alt + Shift + D`.
2. Pick a tool from the toolbar and draw.
3. That's it. Your notes save on their own.

Click the icon again to hide the toolbar. Browser pages like settings and the extension stores don't allow extensions, so the toolbar won't open there.

## Keyboard shortcuts

Tool shortcuts only work while the toolbar is open, so typing on the page works as usual. You can change any shortcut on the **Options** page.

| Action | Shortcut |
| :--- | :---: |
| Show or hide the toolbar | `Alt + Shift + D` |
| Select and move | `V` |
| Pen | `P` |
| Highlighter | `H` |
| Box | `R` |
| Circle | `C` |
| Line | `L` |
| Arrow | `A` |
| Double arrow | `D` |
| Text | `T` |
| Eraser | `E` |
| Undo / Redo | `Ctrl + Z` / `Ctrl + Y` |
| Select all | `Ctrl + A` |
| Delete selected | `Delete` |
| Clear the page | `Alt + Shift + X` |

On a Mac, use `Cmd` instead of `Ctrl` and `Option` instead of `Alt`. Hold `Shift` while drawing a line to keep it straight, or a circle to keep it round.
